Utility

A Motive is a named need with a value; the lower the value, the more urgent. The Utility agent picks the most important Motive, the one with the lowest value.

Drag the sliders, or press Play to let every Motive decay each tick. With “Act on the most important Motive” on, the agent tops up whichever Motive it picked.

    const agent = new utility.UtilityAgent();
agent.motives.push(new utility.Motive("hunger", 0.8));
agent.motives.push(new utility.Motive("thirst", 0.6));

for (const motive of agent.motives) {
  motive.value = Math.max(0, motive.value - decay[motive.name]);
}
agent.getMostImportantMotive().name; // the lowest value
