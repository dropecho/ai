Behavior tree

The root is a Selector of two Sequences and a fallback Task. Each Task node runs a Task registered by name in the Task registry, and every Task reads and writes the Blackboard.

Watch the highlighted nodes: in one tick a Composite runs on to the next child until a child decides the result (SUCCESS for a Selector, FAILURE for a Sequence), the last child finishes, or a child answers RUNNING. Every node that ran this tick is highlighted. A RUNNING child keeps the Composite's cursor (▸) and is asked again next tick, without re-running the children before it.

Tick Reactive root to rebuild the tree with a Reactive Selector at the root. It starts from its first child every tick, so getting hungry while sleeping interrupts the sleep: is_hungry is checked again each tick and eating takes over. The interrupted child is not told; it is simply not ticked again until it is reached again, and the inner Sequence's ▸ still points at sleep, so the nap picks up where it left off once the agent has eaten.

      TaskBank.register("is_hungry", (bb) =>
  bb.get("hunger") >= 3 ? bt.NODE_STATUS.SUCCESS : bt.NODE_STATUS.FAILURE);
// ... eat, is_tired, sleep, wander

const tree = new bt.BehaviorTree(
  new bt.SelectorNode([
    new bt.SequenceNode([new bt.TaskNode("is_hungry"), new bt.TaskNode("eat")]),
    new bt.SequenceNode([new bt.TaskNode("is_tired"), new bt.TaskNode("sleep")]),
    new bt.TaskNode("wander"),
  ]),
);
tree.init(blackboard);
tree.execute(); // once per tick
