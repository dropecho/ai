Behavior tree

The root is a Selector of two Sequences and a fallback Task. Each Task node runs a Task registered by name in the Task registry, and every Task reads and writes the Blackboard.

Watch the highlighted nodes: in one tick a Composite runs on to the next child until a child decides the result (SUCCESS for a Selector, FAILURE for a Sequence), the last child finishes, or a child answers RUNNING. Every node that ran this tick is highlighted. A RUNNING child keeps the Composite's cursor (▸) and is asked again next tick, without re-running the children before it.

Tick Reactive root to rebuild the tree with a Reactive Selector at the root. It starts from its first child every tick, so getting hungry while sleeping interrupts the sleep: is_hungry is checked again each tick and eating takes over. The abandoned branch is halted: sleep when tired and its running sleep are told they will not be ticked again, and the inner Sequence's ▸ goes back to its first child, so the agent checks is_tired afresh once it has eaten.

The page sees all this through a tracer on the tree: parents report every child they run and every child they halt, and a StatusRecorder keeps the last Status of each node for the view and for tree.toText().

      The code
      
      
      TaskBank.register("is_hungry", (bb) =>
  bb.get("hunger") >= 3 ? bt.NODE_STATUS.SUCCESS : bt.NODE_STATUS.FAILURE);
// ... eat, is_tired, sleep, wander

const rootSelector = new bt.SelectorNode([
  new bt.SequenceNode([new bt.TaskNode("is_hungry"), new bt.TaskNode("eat")]),
  new bt.SequenceNode([new bt.TaskNode("is_tired"), new bt.TaskNode("sleep")]),
  new bt.TaskNode("wander"),
]);
const tree = new bt.BehaviorTree(rootSelector);
tree.init(blackboard);
tree.execute(deltaTime); // once per tick

// Watch it run: any object with onTick and onHalt, or the built-in StatusRecorder.
const recorder = new bt.StatusRecorder();
tree.setTracer(recorder);
tree.setLabel(rootSelector, "root"); // Task nodes are labelled with their Task name
recorder.clear();
tree.execute(deltaTime);
console.log(tree.toText(recorder)); // indented tree, each node's Status this tick
tree.toDot(recorder);               // the same as Graphviz DOT

// Reactive root: re-checks "eat when hungry" every tick, even while sleeping.
new bt.SelectorNode([/* same children */], true); // reactive: true
