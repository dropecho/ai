dropecho.ai

A small game AI toolkit for Haxe, JS and C#: four independent ways to decide what an agent does next (behavior tree, state machine, goal planner and utility motives), sharing one Blackboard of facts.

Install

Haxe, with lix or haxelib:

lix install haxelib:dropecho.ai
haxelib install dropecho.ai

JS / TypeScript:

npm install @dropecho/ai

Demos

Each demo runs the library in your browser, built from the same scenarios as its tests.

  • Behavior tree

    A Selector of Sequences over Tasks. Step it and watch each Composite run on through its children in one tick.

  • State machine

    Wander, eat, sleep and flee States with Conditions, an any-transition and a live State graph.

  • Goal planner

    Toggle Actions and edit Costs, see the cheapest Plan the Planner finds, then run it.

  • Utility

    Motives decay over time; the Utility agent picks the most important one, the lowest.
