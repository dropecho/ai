State machine

An agent wanders until it is hungry or exhausted, then eats or sleeps. Danger is an any-transition: from whatever State is current, it moves to flee.

Each tick the current State ticks first, then the state machine takes the first Transition whose Condition is true, checking any-transitions before the current State's own and skipping any Transition to the State it is already in. The State graph below is drawn from fsm.toDot().

State graph

Filled: the current State. Blue edge: the Transition the next tick takes. Dashed outline: the State it leads to.

    The code

    const wander = {
  getName: () => "wander",
  onEnter() {},
  onExit() {},
  tick() {
    blackboard.increment("hunger");
    blackboard.decrement("energy");
  },
};
// ... eat, sleep, flee

const machine = new fsm.FSM();
machine.addTransition(wander, eat, () => blackboard.get("hunger") > 2);
machine.addAnyTransition(flee, () => blackboard.get("danger") > 0); // skipped while already in flee
machine.changeToState(wander); // required before the first tick
machine.tick();
