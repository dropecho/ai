Goal planner

The Planner asks the game which Condition names are true now (the World state), searches every World state reachable from there using each Action's preconditions and postconditions, and returns the cheapest Plan that makes the Goal true, or null when there is none.

By default, buy_weapon reaches the Goal in one step for Cost 10, but find_weapon then get_weapon costs 2 in total, so the Planner picks the two-step Plan. Change the Costs, switch Actions off, or mark Conditions as already true and watch the Plan change.

Run the Plan

Each tick, plan.update(dt) updates the front Action, then drops every front Action that is done. These Actions have no done check of their own, so each is done once its postconditions are in the World state; here an Action makes them true after its number of ticks.

    The code

    const world = new Set(); // the Condition names true in the game
const worldState = () => [...world];

const findWeapon = new goap.Action("find_weapon", (dt) => world.add("found_weapon"), 1,
  [], ["found_weapon"]);
const getWeapon = new goap.Action("get_weapon", (dt) => world.add("has_weapon"), 1,
  ["found_weapon"], ["has_weapon"]);
const buyWeapon = new goap.Action("buy_weapon", (dt) => world.add("has_weapon"), 10,
  [], ["has_weapon"]);

const plan = new goap.Planner(new goap.Goal(["has_weapon"]), [buyWeapon, findWeapon, getWeapon], worldState)
  .generatePlan(); // find_weapon, get_weapon; or null when no Plan reaches the Goal

plan.currentAction();    // the Action running now
plan.remainingActions(); // an Array of the Actions left
const done = plan.update(dt); // once per tick; true when every Action is done

    An Action without a done check of its own is done once all its postconditions are in the World state, so the Plan needs a world state provider (the Planner passes its own on). To decide differently, pass a done check, a () => boolean, as the last goap.Action argument. A Plan that holds an Action with neither throws when it is created.
