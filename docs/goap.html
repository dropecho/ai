Goal planner

The Planner searches every World state reachable from the empty one, using each Action's preconditions and postconditions, and returns the cheapest Plan that makes the Goal true, or null when there is none.

By default, buy_weapon reaches the Goal in one step for Cost 10, but find_weapon then get_weapon costs 2 in total, so the Planner picks the two-step Plan. Change the Costs or switch Actions off and watch the Plan change.

Run the Plan

Each tick, plan.update(dt) updates the front Action, then drops every front Action whose done check is true. Here an Action is done after its number of ticks.

    The code

    const findWeapon = new goap.Action("find_weapon", (dt) => progress.find++, 1,
  [], ["found_weapon"], null, () => progress.find >= 2);
const getWeapon = new goap.Action("get_weapon", (dt) => progress.get++, 1,
  ["found_weapon"], ["has_weapon"], null, () => progress.get >= 1);
const buyWeapon = new goap.Action("buy_weapon", (dt) => progress.buy++, 10,
  [], ["has_weapon"], null, () => progress.buy >= 3);

const plan = new goap.Planner(new goap.State(["has_weapon"]), [buyWeapon, findWeapon, getWeapon])
  .generatePlan(); // find_weapon, get_weapon; or null when no Plan reaches the Goal

const done = plan.update(dt); // once per tick; true when every Action is done

    The done check is the last constructor argument. It defaults to always true, which would drop every Action on the first update, so pass a real one.
