package dropecho.ai.goap

@:expose("goap.Action")

Something an agent can do: the Planner chains Actions by their conditions and Cost, and a Plan runs them.

  • The Condition names this Action makes true, for planning; defaults to none.
preMatcher
  • The game-defined can-start check; defaults to always true and is not called by the library.
postMatcher
  • The done check; defaults to always done, so a Plan drops this Action after its first update.
