class BehaviorTree

package dropecho.ai.bt

implements IParentNode, Node

@:expose("bt.BehaviorTree")

A behavior tree: a root node run once per tick, whose Status is the tree's Status.

Call init once before the first execute. setTracer reports every node run or halted; toText and toDot write the tree out.

Constructor

new(root:Node)

Creates a tree around a root node.

Parameters:

root
  • The root node, usually a Composite; throws if null.

Methods

children():Array<Node>

Lists the root.

Returns:

A new array holding the root.

execute(deltaTime:Float):NODE_STATUS

Runs one tick of the tree from its root.

Parameters:

deltaTime
  • The time since the last tick, in the game's time unit.

Returns:

The root's Status for this tick; RUNNING means call again next tick.

halt():Void

Halts the root, for example when the game stops running this tree while it is RUNNING.

init(context:Blackboard):Void

Gives the Blackboard to every node in the tree.

Parameters:

context
  • The Blackboard the nodes read and write; a new empty one is used if null.

labelOf(node:Node):Null<String>

Gives a node's label: the one set with setLabel, else the node's own (ILabeled), else null.

Parameters:

node
  • The node asked about.

Returns:

The label, or null for none.

setLabel(node:Node, label:Null<String>):Void

Names a node in this tree's dumps, in place of any label the node has of its own (a Task node's Task name).

Parameters:

node
  • The node to name.
label
  • The name; null removes it.

setTracer(tracer:Null<ITreeTracer>):Void

Reports every node executed or halted in this tree to tracer, from the root down. The tracer is handed to the parent nodes in the tree now, so call it again after adding nodes to the tree.

Parameters:

tracer
  • The tracer, e.g. a StatusRecorder; null to stop tracing.

toDot(?recorder:StatusRecorder):String

Writes the tree as a Graphviz digraph, one DOT node per tree node by identity, labelled like toText. With a recorder, nodes that ran or were halted get a class attribute: "success", "failure" or "running", and/or "halted".

Parameters:

recorder
  • The StatusRecorder traced into this tree; leave out for no classes.

Returns:

The DOT source.

toText(?recorder:StatusRecorder):String

Writes the tree as indented text, one node per line: its class name, its quoted label if it has one, and with a recorder its last Status ("-" if it has not run) and "(halted)" if it was halted.

Parameters:

recorder
  • The StatusRecorder traced into this tree; leave out to print names only.

Returns:

The text, lines joined with newlines.
