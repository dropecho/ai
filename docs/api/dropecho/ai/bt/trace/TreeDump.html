class TreeDump

package dropecho.ai.bt.trace

@:directlyUsed

Writes a behavior tree out as indented text or Graphviz DOT, walking it through IParentNode.children.

Static methods

statictoDot(root:Node, nameOf:Node ‑> String, recorder:Null<StatusRecorder>):String

Writes a Graphviz digraph with one DOT node per tree node (ids by identity, so a shared node appears once) and an edge to each child. With a recorder, a node that ran or was halted gets a class of its lowercase last Status and/or "halted".

Parameters:

root
  • The node to start from.
nameOf
  • Gives the label drawn for a node.
recorder
  • Where the Statuses come from; null for no classes.

Returns:

The DOT source.

statictoText(root:Node, nameOf:Node ‑> String, recorder:Null<StatusRecorder>):String

Writes one line per node, children indented two spaces under their parent. With a recorder, each line ends with the node's last Status ("-" if it has not run) and "(halted)" if it was halted.

Parameters:

root
  • The node to start from.
nameOf
  • Gives the name printed for a node.
recorder
  • Where the Statuses come from; null to print names only.

Returns:

The lines, joined with newlines.
