class WaitNode

package dropecho.ai.bt.node

extends LeafNode

@:expose("bt.WaitNode")

A Wait: a leaf that is RUNNING until a length of time has passed, then succeeds.

Time counts from the tick the wait starts on, using the deltaTime of the ticks after it, so it only advances on ticks the node receives. After succeeding or being halted it starts afresh.

Constructor

new(duration:Float)

Creates a Wait.

Parameters:

duration
  • How long to wait, in the game's time unit (the unit it passes as deltaTime); throws unless finite and at least 0.

Methods

execute(deltaTime:Float):NODE_STATUS

Advances the wait by one tick.

Parameters:

deltaTime
  • The time since the last tick, in the game's time unit; ignored on the tick the wait starts.

Returns:

SUCCESS on the tick the waited time reaches the duration, otherwise RUNNING.

halt():Void

Forgets the time waited so far, so the next tick starts a new wait.
