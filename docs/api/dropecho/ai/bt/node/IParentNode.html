interface IParentNode

package dropecho.ai.bt.node

extended by CompositeNode, ParallelNode, DecoratorNode, BehaviorTree

@:directlyUsed@:expose("bt.IParentNode")

A node with children (a Composite, Parallel, Decorator or whole tree): it can list them and report on them to a tracer.

Methods

children():Array<Node>

Lists the children, in the order they run.

Returns:

A copy of the children; changing it does not change the node.

setTracer(tracer:Null<ITreeTracer>):Void

Makes this node and every parent below it report each child they execute or halt to tracer.

Parameters:

tracer
  • The tracer, or null to stop tracing.
