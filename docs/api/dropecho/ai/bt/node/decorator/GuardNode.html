class GuardNode

package dropecho.ai.bt.node.decorator

extends DecoratorNode

implements IAbortsLowerPriority

@:expose("bt.GuardNode")

A Guard (precondition): runs its child only while a Check is true.

Its Abort mode says when the Check is asked again while something is already running: SELF re-asks it every tick while the child runs and halts the child when it turns false; LOWER_PRIORITY lets a non-reactive parent re-ask it while a later sibling runs, and abandon that sibling when the Check changes in the Guard's favour.

Parameters:

Returns:

FAILURE if the Check is false (a running child is halted), otherwise the child's Status.

halt():Void

Halts the child if it is running.

wantsToAbortLowerPriority(decidingStatus:NODE_STATUS):Bool

Re-asks the Check when the Abort mode has LOWER_PRIORITY. It wants to abort only when the answer changed since it was last asked, in the direction that changes the parent's outcome: to true under a Selector, to false under a Sequence.

Parameters:

decidingStatus
  • The parent's deciding Status: SUCCESS for a Selector, FAILURE for a Sequence.

Returns:

True if the parent should halt its running child and run again from this Guard.
