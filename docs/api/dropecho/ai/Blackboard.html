class Blackboard

package dropecho.ai

@:directlyUsed@:expose("Blackboard")

The shared facts an agent's AI reads and writes. A fact is a named number and reads as 0 if never set. A value is a named piece of data of any type, read and written through a typed BlackboardKey, and reads as null if never set. Facts and values are separate: the same name can hold both, and onChange listeners for that name hear about either.

onChange(key:String, listener:ChangeListener):Action_0

Calls listener with key after the fact or value named key changes, in the order listeners were added. Listeners may be added or removed while listeners are being called: one added then waits for the next change, one removed is not called again.

Parameters:

key
  • The name of the fact or value to watch.
listener
  • Called with key after each change.

Returns:

A function that removes this listener; calling it again does nothing.
