class FSM

package dropecho.ai.fsm

@:expose("fsm.FSM")@:nativeGen

A state machine: holds one current State and changes State when a Transition's Condition becomes true. Call changeToState to set the first State before calling tick.

Constructor

new()

Creates a state machine with no State and no Transitions.

Methods

addAnyTransition(to:IState, condition:Condition):Void

Adds an Any-transition to to, taken from whatever State is current when condition is true. Any-transitions are checked before the current State's own Transitions, in the order added.

Parameters:

to
  • The State the Transition moves to.
condition
  • The Condition that takes the Transition.

addTransition(fromState:IState, toState:IState, condition:Condition):Void

Adds a Transition from fromState to toState, taken when condition is true. Transitions belong to fromState itself, not its name, and are checked in the order they were added.

Parameters:

fromState
  • The State the Transition leaves from.
toState
  • The State the Transition moves to.
condition
  • The Condition that takes the Transition.

changeToState(state:IState):Void

Moves to state: calls the current State's onExit (if any), then state.onEnter. Runs even if state is already current.

Parameters:

state
  • The State to change to.

getCurrentState():IState

Gets the State the machine is in.

Returns:

The current State, or null before the first changeToState.

tick():Void

Ticks the current State, then takes the first Transition whose Condition is true. Any-transitions are checked before the current State's own Transitions. Throws if no State has been set with changeToState.

toDot():String

Draws the State graph as Graphviz DOT, marking the current State and the Transition about to be taken with class="active". It calls every Condition up to the first true one to find that Transition. Only States with their own Transitions appear as nodes; Any-transitions start from a node named any.

Returns:

The DOT source.
