Blackboard

The shared facts an agent's AI reads and writes. A fact is a named number and reads as 0 if never set. A value is a named piece of data of any type, read and written through a typed BlackboardKey, and reads as null if never set. Facts and values are separate: the same name can hold both, and onChange listeners for that name hear about either.

BlackboardKey

The name of a typed Blackboard value, carrying the value's type T at compile time. At runtime it is the plain String name, so JS callers pass strings and nothing extra is generated. Any String converts to a key, so bb.getValue(("target" : BlackboardKey<Entity>)) and a shared new BlackboardKey<Entity>("target") read the same value.

ChangeListener

A game-defined function told the name of a Blackboard fact or value that just changed.

Task

A game-defined function that does a leaf's work: it gets the Blackboard and the time since the last tick, and returns a Status.

TaskBank

The Task registry: game code registers Tasks by name so behavior trees can refer to them by name. It is global (static).

TaskMap

Tasks keyed by name.
